# 네트워크 용어 정의
## internet 
internetworking 에서 유래됨

## Internet
TCP/IP 기반 네트워크로 우리가 사용하는 인터넷을 지칭함

## 인터페이스(Interface)
시스템과 전송 매체의 연결 지점에 대한 규칙

## 프로토콜(protocol)
시스템이 데이터를 교환할 때 사용하는 소프트웨어적 규칙

## 시스템(system)
내부 규칙에 따라 자율적으로 동작하는 대상
물리적 : 컴퓨터, 자동차 ..
논리적 : 운영체제, 프로세스 ..

> [!NOTE]- CPU, MCU 차이
> CPU는 제어, 연산 두 가지의 기능을 수행하나 MCU는 제어, 연산 뿐만 아니라 메모리, 스토리지 또한 포함된 것


# 시스템의 구분
## 노드(node)
컴퓨터 이론 분야에서 특정 시스템을 가르키는 일반적인 용어로 데이터를 주고 받을 수 있는 모든 시스템을 노드라 한다.

## 호스트(host)
컴퓨팅 기능이 있는 시스템으로 인터넷 바깥쪽에서 일반 사용자의 창구 역할을 한다.

> [!NOTE]- 노트, 호스트 차이
> 호스트는 컴퓨팅 기능을 수행할 수 있다. 여기서 컴퓨팅 기능이란 우리가 일반적으로 앱을 설치하고 실행하는 것을 말한다.


## 라우터(router)
인터넷 내부를 구성하며, 기본으로 데이터 전송 기능을 포함한다. 
네트워크를 통해 데이터를 전송할 때 경로를 설정함

# 계층 모델
## 계층(layer)
N 계층과 다른 노드의 N계층 간의 관계

## 프로토콜
계층간의 통신 규약

## 인터페이스
상하위 계층간의 규칙으로 하위에서 상위 인터페이스를 서비스라 한다.

## OSI 7계층 모델

1. 물리 계층 : 호스트를 전송 매체와 연결하기 위한 인터페이스와 전송 매체 특성을 다룸
2. 데이터 링크 계층 : 물리 계층의 오류를 해결
   오류 제어(error control) : 전류 오류 감지 -> 재전송
   흐름 제어(flow control) : 
3. 네트워크 계층 : 주소(adress), 호스트와 호스트 사이의 올바른 전송 경로 선택(혼잡 제어 포함) -> 라우터의 기능
4. 전송 계층 : 송수신 프로세스 사이의 논리적 연결(end-to-end) 지원. 안전한 데이터 전송
   TCP/IP, UDP 가 이 계층에 포함되며 TCP 에서 종단간의 흐름제어, 오류제어를 지원함
5. 세션 계층 : 대화(dialog) 개념을 지원하는 상위의 연결 지원
   동기화(synchronization) :
6. 표현 계층 : 데이터의 표현 방법, 압축(compression), 암호화(Encryption/Decryption)
7. 응용 계층 : 우리가 사용하는 일반적인 앱 등.
