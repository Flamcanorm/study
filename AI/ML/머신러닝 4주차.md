## Error case in SVM

![](../../img/스크린샷%202026-09-23%20오후%202.42.55.png)

실제 데이터에는 에러가 존재한다.

선형 판별경계선(linear decision boundary)으로 에러가 포함된 데이터를 완전하게 분류하는 것은 불가능함

에러를 어떻게 처리할 것인가?
1. 비선형 decision boundary
2. error 허용 -> 에러를 포함시켜 방정식을 구성


## 에러 허용 방법
방법 1 ) 0-1 Loss (에러가 있거나 없거나)
min_w,b || w || + C x #_error(number-of-error)  C : constant (에러의 비중을 조정)

decision boundary 로부터 떨어진 거리에 상관없이 loss가 동일한 1이 됨

방법 2) Hinge Loss
