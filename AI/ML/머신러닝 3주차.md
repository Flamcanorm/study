## 의사결정 트리의 문제점
주어진 데이터셋에 대해 작업을 수행하였으나 실제 환경에서는 아주 많은 노이즈(noise)와 불일치성(inconsistencies)를 포함하고 있기 때문에 완벽하지 않음
- noise
- inconsistencies (사람에 따라 다른 불일치성)
- over-fitting (학습시킨 데이터셋에만 치중되게 학습된 것) <-> under-fitting

노이즈가 포함된 데이터셋을 조정할 수 있어야하고 에러들에 대해서 견고해야함

# Random Forest(RF)
랜덤하게 생성한 트리 여러 개 모음 -> 앙상블 기법 중 하나

보통 데이터를 여러 트리에 적용하여 결과값을 모아 가장 많이 선택된 결과(voting)을 선택함

# 앙상블 기법(Ensemble Methods)
모델 결합(Model Combining) 방법이라 부름

특정한 하나의 예측방법이 아닌 복수의 예측 모델을 결합하여 더 나은 성능의 예측을 하려는 것
- 단일 모델을 사용할 때보다 성능 분산이 감소
- 과적합(Over-fitting) 방지

하나의 기법만을 사용하는 방법 (RF)과 여러 기법을 사용하는 방법이 있음

- Aggregation 기법 : 사용할 모델 집합이 결정되어 있음
- Boosting 기법 : 사용할 모델을 점진적으로 늘려감

## 다수결(Majority Voting)
- hard voting : 단순 투표, 개별 모형의 결과를 기준으로 선택
- soft voting : 가중치 투표, 개별 모형의 조건부 확률의 합 기준
