## 지도 학습(Supervised Learning)
- 분류(Classificaon) : 스팸 메일을 걸러줬으면 좋겠다 -> 스팸 필터, 중요도 계산 등 (이진분류, 삼진분류)
  - [DT](/)(Decision Tree), RF(Random Forest), SVM(Support Vector Machine)
  - Naive Beyes, XGBoost, LightGBM, CatBoost, **Neural Network**
- 예측(Prediction) : 내년 아파트 가격은 어떻게 될 것인가?
  - 선형회귀(Linear Regression), 로지스틱 회귀(Logistic Regression)


> [!NOTE] 개 vs 고양이
> 정답(label)을 알려주고 학습
> 특징(feature)을 분류하고 예측 -> 가중치

> [!NOTE] ML vs DL
> ML : 데이터분석가가 feature을 정해줌
> DL : Model이 feature을 정해서 분석

feature 에 따라 뎁스가 결정
어떤 feature를 먼저 사용하느냐에 따라 트리의 모양이 달라짐

Function approximation
- hypothesis 가설 설정 -> 가설등 중에서 어떤 가설이 가장 데이터셋에 맞나
- Target function 
 
 
 Entropy : 의사결정 트리를 만들 때 사용해야될 좋은 속성(attribute, 특징값)은 어떤것들인가?
 - 불확실성이 적은 것
 - 여러 가지로 고루 분산되어 있으면 엔트리피가 높고, 특정한 하나의 상태에 몰려있으면 엔트리피가 낮다

특징 변수의 불순도(불확실성) 측정 방법 
c개의 클래스로 분류되는 학습 데이터가 있는 경우, 노드 t에 존재하는 데이터 중 i 클래스(1<=i<=c)에 속하는 데이터의 비율을 p(i/t)로 표현하기로 할 경우에 대해
1. 지니 인덱스(Gini index)
2. 엔트로피(Entropy, Gini Index에 정규화 개념을 포함한 것)
3. 분류 오류(misclassification error)

> [!NOTE] 로그의 의미

정보 이득(information gain)
클래스 변수의 원래 불확실성 레벨에서 f라는 특징값(attribute)을 조건으로 주었을 경우 클래스 변수의 불확실성이 어떻게 바뀌었는가 를 측정하기 위한 정도
